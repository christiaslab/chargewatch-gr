# Security Policy

## Supported versions

Only `main` is supported. There are no maintained release branches.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's private vulnerability
reporting: open the repository's **Security** tab and select **"Report a
vulnerability"**. Do not open a public issue for security reports.

## Response

This is a solo-maintained project. Reports are handled on a best-effort basis, with
acknowledgement within 7 days.

## Scope

The data served by this project comes from a public Greek government open-data feed.
The repository holds no secrets — credentials live in Google Secret Manager, not in
code or config here.

The upstream feed itself (its infrastructure, availability, or data quality) is out of
scope for this policy.
